# Sprint 035 — preparação do primeiro teste no celular

## Objetivo

Preparar a Beta para instalação controlada no celular, validar login, navegação e dados de demonstração e padronizar o registro de erros, sem adicionar funcionalidades.

## Alterações

- Versão atualizada para `1.0.0-beta06` (`versionCode 36`).
- Guia completo de instalação e primeiro teste no celular.
- Checklist funcional por módulo.
- Lista oficial das contas de demonstração.
- Modelo padronizado para relatar erros.
- Script Windows e shell para montar um pacote do APK com documentação e SHA-256.
- Verificação estática ampliada para conferir os artefatos da Sprint 035.

# Como registrar erros da Beta

Para corrigir rapidamente, registre **um erro por vez**.

## Informações obrigatórias

```text
Título curto:
Tela onde aconteceu:
Usuário utilizado:
O que eu estava fazendo:
O que eu esperava:
O que aconteceu:
O erro acontece sempre? Sim/Não
Modelo do celular:
Versão do Android:
```

Anexe, quando possível:

- captura de tela;
- gravação curta da tela;
- texto completo da mensagem;
- arquivo de log do build, se o erro ocorrer na compilação.

## Exemplo

```text
Título curto: Classificação não atualizou
Tela onde aconteceu: Rodada 1
Usuário utilizado: admin
O que eu estava fazendo: Salvei Torino 2 x 0 Girona
O que eu esperava: Torino com 3 pontos
O que aconteceu: A tabela continuou zerada
O erro acontece sempre? Sim
Modelo do celular: POCO ...
Versão do Android: 15
```

## Prioridade

- **Crítico:** aplicativo não abre, fecha sozinho, perde dados ou corrompe backup.
- **Alto:** login, placar, classificação, financeiro ou mercado não funcionam.
- **Médio:** tela, filtro ou navegação funciona parcialmente.
- **Baixo:** texto, alinhamento, cor ou animação.

## Regra para correção

Não reinstale nem apague os dados antes de registrar o erro, exceto se o aplicativo impedir completamente o uso.

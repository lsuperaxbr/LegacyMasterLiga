# Checklist do primeiro teste Beta

Marque cada item como: **OK**, **ERRO** ou **NÃO TESTADO**.

## Instalação

- [ ] APK instalado sem erro.
- [ ] Aplicativo abre sem fechar sozinho.
- [ ] Ícone e nome aparecem corretamente.

## Login

- [ ] `admin / admin123` entra no Dashboard.
- [ ] Senha incorreta mostra mensagem clara.
- [ ] Logout retorna ao Login.
- [ ] Sessão continua ativa ao reabrir o aplicativo.

## Dados de demonstração

- [ ] Liga M L Amigos existe.
- [ ] Moeda exibida como CR.
- [ ] Torino aparece com Tomascote e 500 CR.
- [ ] Fluminense aparece com Richemont e 500 CR.
- [ ] Bournemouth aparece com Pipocacr7 e 500 CR.
- [ ] Girona aparece com LSuperax e 500 CR.
- [ ] Liga Principal está em ida e volta.

## Navegação

- [ ] Dashboard abre todos os atalhos permitidos.
- [ ] Botão Voltar funciona.
- [ ] Nenhuma tela fica vazia sem explicação.
- [ ] Usuário Visitante não acessa áreas protegidas.
- [ ] Presidente não acessa o Painel Administrativo.

## Partidas e classificação

- [ ] Rodadas aparecem separadas por temporada.
- [ ] Resultado pode ser salvo.
- [ ] Resultado pode ser corrigido.
- [ ] J, V, E, D, PTS, GP, GC e SG atualizam.
- [ ] Aproveitamento atualiza.
- [ ] Primeiro colocado aparece em amarelo.

## Mercado e Financeiro

- [ ] Transferência exige jogador, origem, destino e valor.
- [ ] Saldo insuficiente bloqueia a operação.
- [ ] Compra debita o comprador.
- [ ] Venda credita o vendedor ou Banco da Liga.
- [ ] Extrato registra a movimentação em CR.
- [ ] Transferência gera notícia automática.

## Histórico, notícias e auditoria

- [ ] Notícias abrem e podem ser filtradas.
- [ ] Auditoria registra ações administrativas.
- [ ] Histórico não mistura competições ou temporadas.

## Backup

- [ ] Backup manual é criado.
- [ ] Arquivo pode ser exportado.
- [ ] Validação de integridade funciona.
- [ ] Restauração cria uma cópia de segurança antes.

## Resultado final

- [ ] APROVADO PARA CONTINUAR OS TESTES.
- [ ] NECESSITA CORREÇÕES ANTES DE USAR DADOS REAIS.

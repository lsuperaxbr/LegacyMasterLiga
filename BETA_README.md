# Legacy Master Liga — Beta 1

Primeira base preparada para testes reais do aplicativo Android.

## Versão

```text
1.0.0-beta02
versionCode 32
```

## Conteúdo do pacote

- Projeto Android Studio completo.
- Variante Debug.
- Variante Beta instalável separadamente.
- Variante Release preparada para assinatura privada.
- Testes unitários e instrumentados.
- Documentação de instalação, testes e geração de APK.
- Scripts de build para Windows e Linux/macOS.

## Documentos

- `docs/INSTALACAO_BETA.md`
- `docs/PLANO_DE_TESTES_BETA.md`
- `docs/RELEASE_BETA.md`
- `docs/CHECKLIST_BETA.md`
- `SPRINT_030_REPORT.md`

## Atenção

A compilação Gradle completa deve ser confirmada em um Android Studio com acesso às dependências. O pacote não contém uma chave privada de assinatura nem um APK pré-compilado.
